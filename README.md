# Portal Educacional - Eletroeletrônica

Projeto de software desenvolvido para a disciplina de Eletroeletrônica, com o objetivo de abrigar conteúdos informativos sobre conceitos de elétrica e eletrônica.

## 👥 Integrantes
* **Alunas:** Nicole, Pyetra e Valentina
* **Turma:** Albert Einstein
* **Tópico Atribuído:** 5.2 - Materiais Condutores, Isolantes e Semicondutores

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação das páginas e conteúdos.
* **CSS3:** Estilização com paleta de cores personalizada em Marrom e Bege.
* **JavaScript:** Lógica de navegação entre módulos e Quiz interativo.

## 🎨 Identidade Visual
* **Paleta de Cores:** Tons de Marrom Terracota (`#8c5a3c`) e Bege (`#fdfbf7` / `#f5efe6`).
* **Tipografia:** Fonte 'Inter' do Google Fonts para garantir leitura limpa e organizada.

## 🚀 Como Executar o Projeto
1. Clone o repositório ou baixe os arquivos em ZIP.
2. Abra a pasta do projeto no **VSCode**.
3. Abra o arquivo `index.html` utilizando a extensão **Live Server** ou dando duplo clique no arquivo para abrir no navegador.
